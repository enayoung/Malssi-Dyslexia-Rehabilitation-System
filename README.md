# 🌱 말씨 — 씨앗의 말 정원

언어를 잃은 세상에 남은 **아기 씨앗에게 소리와 글을 알려주는** 읽기·쓰기 놀이입니다.
난독증 관련 읽기·쓰기 어려움을 가진 아이가 “틀릴까 봐” 읽기를 피하지 않도록,
**정답/오답 판정 대신 응답 유형에 따른 단계적 간접 피드백**을 주고, **재시도 자체를 씨앗의 성장**으로 보상합니다.

> 특허 출원 명세서 「난독증을 위한 응답 유형 분류 기반의 단계적 간접 피드백을 제공하는 읽기·쓰기 훈련 시스템 및 그 제공 방법」의 실시예를 웹 게임으로 구현한 것입니다.
> 기록되는 값은 학습 진행 확인용이며, 의학적 진단이나 임상적 효과를 뜻하지 않습니다.

## 실행

빌드 과정이 없는 정적 웹앱입니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 엽니다.

- **음성 입력(🎤 말하기)** 은 Chrome·Edge의 Web Speech API(ko-KR)를 씁니다. 마이크 권한이 필요하고, `localhost` 또는 `https` 에서만 동작합니다.
- 음성 인식을 못 쓰는 환경에서는 자동으로 **👆 누르기** 방법으로 진행됩니다 (상단 버튼으로 바꿀 수 있음).
- 진행 상황은 브라우저 `localStorage` 에 저장됩니다.

테스트:

```bash
node --test tests/*.test.js
```

## 활동 (학습 콘텐츠 제공부)

| 활동 | 내용 |
|---|---|
| 이름 짓기 | 처음 시작할 때 씨앗 이름 짓기. 어떤 이름이든 그대로 받아들임 |
| 📖 단어 읽기 | 1단계 그림+글자+소리 따라 읽기 / 2단계 그림+글자, 소리 힌트 / 3단계 글자 먼저 읽고 그림으로 확인. 누르기 모드에서는 글자를 보고 맞는 소리를 골라 들려줌 |
| 📚 동화 읽기 | 7장짜리 이야기 지도에서 장을 골라 문장을 한 줄씩 소리 내어 읽기 → 세 문장이 모이면 장 완성 → 이해 질문. 기대와 다른 답이면 관련 문장을 크게 보여 주며 다시 읽기. 앞 장을 완성하면 다음 장이 열림 (`reading-sentence/` 별도 페이지) |
| ✏️ 단어 쓰기 | 비슷한 소리 두 낱말(발↔벌) 비교 후 첫소리·가운데 소리·끝소리 타일로 낱말 만들기. 다른 뜻 있는 낱말이 되면 그 그림이 피어남 |
| 🧩 문장 쓰기 | 빈칸 채우기 / 카드 늘어놓기 / 그림 보고 문장 만들기 / 이상한 말 찾기(“오늘 목장에 달이 빠르게 달려요.”) |

## 간접 피드백 구조

```
응답 ─▶ 자소 단위 비교·이력 기록 ─▶ 응답 유형 분류 ─▶ 지원 수준 결정 ─▶ 피드백 생성 ─▶ 평가어 검증 ─▶ 출력 + 경험치
```

**응답 유형 (js/engine.js `classifyWord` / `classifySentence`)**

| 유형 | 조건 | 씨앗의 반응 |
|---|---|---|
| A 목표 도달 | 목표와 일치(허용 범위 포함) | 고개 끄덕임, “이제 알겠어. 고마워!” 후 다음 과제 |
| B 유의미 대체 | 다르지만 어휘 데이터에 있는 말 (발→벌) | 🐝가 피어나고 발↔벌을 나란히, 다른 자소(ㅏ/ㅓ) 강조, “벌이 나타났네! 그럼 ‘발’은 어떻게 말해?” |
| C 무의미 | 어휘에 없는 조합(뱔) 또는 인식 실패 | 이미지·경고음·빨간색 없이 갸웃, “음… 처음 듣는 소리야. 한 번 더 들려줄래?” |
| D 무응답 | 기준 시간(단어 8초) 동안 입력 없음 | 씨앗이 먼저 모델 음성 + 글자 하이라이트, “이제 너도 들려줄래?” |

**지원 수준 (`decideLevel`)** — 같은 과제의 재시도 횟수에 따라

- L1 (1회): 재요청만
- L2 (2회): 혼동 글자 굵게 + 글자 크기·자간 확대 + 씨앗이 가리킴, 자소 풀어 보여주기
- L3 (3회): 모델 음성 재생 후 “우리 같이 읽어 볼까?”
- L4 (4회 이상 또는 시간 초과): **보류 목록**에 저장하고 “이 말은 씨앗이 꼭 기억해 둘게. 다음에 또 알려줘!” → 다음 과제. 보류 과제는 다음에 먼저 다시 나옴
- 혼동 자소 누적 빈도가 기준(3회) 이상인 글자가 있으면 처음부터 L2 강조

**평가어 검증 (`verifyText`)** — “정답, 오답, 틀렸어, 실패, 점수, 훈련, 치료, 다시 해 …” 가 들어간 문장은 같은 의도의 대체 문장으로 바꿉니다. 화면에 나가는 모든 씨앗 대사가 이 검증을 거칩니다.

**과정 메시지 (`processMessages`)** — “오늘은 여기까지”를 누르면 정답률 같은 숫자 대신
“어려운 소리도 끝까지 여러 번 들려주었어요.” 같은 과정 중심 메시지를 보여줍니다.

**성장** — 최초 도전 +1, 재시도 +1, 완료 +2 EXP. 10 단위로 씨앗 → 발아 → 새싹 → 묘목 → 성목 → 꽃·열매. 화면에는 숫자 없이 막대와 씨앗 모습만 보입니다.

## 파일 구성

```
index.html
css/common.css         두 페이지 공통: 색·글꼴·상단 바·씨앗 애니메이션·버튼·축하 창
css/style.css          처음 화면 전용
js/
  hangul.js            자소 분해·비교 (수행 기록·분석부 140)
  engine.js            간접 피드백부 170: 분류·지원 수준·대사·평가어 검증·과정 메시지, 성장 정책 180
  speech.js            음성 인식·모델 음성 (사용자 입력 수신부 130)
  store.js             저장: 이력·혼동 자소·보류 목록·경험치 (데이터 저장부 150)
  seed.js              씨앗 캐릭터·반응 애니메이션·말풍선 (동화 읽기 페이지도 같은 씨앗 사용)
  growth.js            경험치·성장 단계·자랄 때 축하 (두 페이지 공통)
  core.js              화면 공통 + 과제 진행기 TaskRun(S500~S560) + 홈·이름 짓기·설정
  main.js              시작

  content/             ← 낱말·문장·동화 내용만 고칠 때
    vocab.js             공통 어휘(낱말 → 그림). 유의미 대체(B) 판별 기준
    read-word.js         읽기-단어: 낱말 목록, 비슷한 소리 후보
    write-word.js        쓰기-단어: 목표/비교 낱말, 자음·모음 타일
    write-sentence.js    쓰기-문장: 빈칸·카드·그림·이상한 말 찾기 과제

  activities/          ← 활동 화면·진행 방식을 고칠 때
    read-word.js         읽기-단어 (1~3단계)
    read-sentence.js     읽기-문장 타일 (reading-sentence/ 페이지로 이동)
    write-word.js        쓰기-단어 (비교 → 타일로 만들기)
    write-sentence.js    쓰기-문장 (4가지 유형)

reading-sentence/      ← 읽기-문장(동화)은 독립 페이지
  index.html
  story.js               동화 7장: 문장 3개 + 이해 질문 (options[0]이 기대 응답, related는 다시 읽을 문장 번호)
  app.js                 이야기 지도 → 문장 읽기 → 질문 → 재읽기, L1~L4 간접 피드백 (맨 위 CFG에서 기준값 조정)
  hangul.js              자소 단위 문장·단어 유사도 (잘 안 들린 단어만 강조)
  style.css

tests/engine.test.js, tests/reading-sentence.test.js
```

동화 읽기 페이지도 처음 화면과 같은 씨앗·경험치를 씁니다. 문장을 읽거나 질문에 답하면 같은 씨앗이 자라고, 상단 🏡 또는 ‘정원으로 🏡’로 돌아갑니다.
읽기-문장 페이지는 `reading-sentence/?dev` 로 열면 음성 대신 글자를 입력해 흐름을 확인할 수 있습니다.

### 콘텐츠 고치는 법

- **낱말 추가**: `js/content/vocab.js` 에 `'낱말': '그림'` 을 넣은 뒤, 원하는 활동의 콘텐츠 파일에 과제를 추가합니다.
- **동화 고치기**: `reading-sentence/story.js` 에서 장마다 문장과 질문을 고칩니다.
- 각 콘텐츠 파일 맨 위 주석에 항목 설명이 있습니다. 고친 뒤 `node --test tests/*.test.js` 로 데이터가 맞는지 확인할 수 있습니다.

### 새 활동 추가하는 법

`js/activities/` 에 파일을 만들고 `SG.core` 도구로 화면을 그린 다음
`SG.registerActivity({ key, order, icon, title, desc, start })` 로 등록하고, `index.html` 에 `<script>` 한 줄을 추가하면 홈 화면에 나타납니다.
